How I Made This

This entire website was built using AI — no hand-written code, no manual deployment. Here are the exact prompts I used and what Claude produced at each step.

For my CSIT 212 final project, the requirement was to use AI completely — no coding or deployment done by me. I used Claude (Anthropic) as my AI assistant to build this full multi-page gift guide website from scratch through a series of natural language prompts.

The process was entirely conversational: I described what I wanted, Claude wrote the code, I reviewed it, and refined it with follow-up prompts. Below is a documented walk-through of every major prompt and a summary of what it produced.

1

Initial Website Request

My Prompt
Prompt #1 — Project Setup
"Can you make me a website for my CSIT 212 Final project, requirements set by the professor are: - I must completely use AI - No coding or deployment should be done by me - The website should be accessible to the public (we will use GitHub) - I have the freedom to use this website for anything I would like I would like to build a website to help people search for gift ideas for their mothers and fathers for Mother's and Father's Day. I would like the website to include two separate pages — one for mothers and the other for fathers — with gifts targeted towards each. Please include images of products, title, and a button that takes the user to the product page."
What Claude Built

Claude generated a complete 3-file website from a single prompt:

  • index.html — A landing page with animated hero cards linking to each gift guide
  • mothers-day.html — 15 gifts across Pampering, Jewelry, Food, and Experiences with product images, descriptions, prices, and "Shop Now" buttons linking to Amazon
  • fathers-day.html — 15 gifts across Tech, Outdoor, Food, and Style categories
  • README.md — Step-by-step GitHub Pages deployment instructions
3 HTML files 30 gift cards total Live product links GitHub deploy guide

More Gifts + Specific Brands

My Prompt
Prompt #2 — Content Expansion
"Can you add more gifts, about 10 more for each. For mothers maybe include: - Sneakers like Nike - Skincare products For fathers maybe include: - Hunting knives from MKC and Benchmade - Bow accessories like Spot Hogg sights Also include search and search filters based on age and categories."
What Claude Built

Claude expanded both pages from 15 to 25 gifts each and added a fully functional search and filter system — all without any code written by me.

  • Mother's page additions: Nike Air Max, Nike Free Run, CeraVe Skincare Set, Luxury Anti-Aging Set, Gua Sha & Jade Roller, Laneige Lip Care, Korean Sheet Mask Collection, Cashmere Cardigan, Birthstone Ring, Percussion Massage Gun
  • Father's page additions: MKC Montana Hunter Knife, MKC Steak Knife Set, Benchmade Griptilian, Benchmade Saddle Mountain Skinner, Spot Hogg Fast Eddie XL Sight, Spot Hogg Hogg It Sight, Carbon Express Arrows, Solar Lantern, 4K Dash Cam, National Park Pass
  • Search bar that filters by title and keywords in real time as you type
  • Category filters (e.g. Spa, Skincare, Jewelry, Hunting, Outdoor, Tech)
  • Age filters (Under 40 / 40–60 / 60+) that show contextually appropriate gifts

Earthy Redesign

My Prompt
Prompt #3 — Visual Redesign
"Can you change the design to something warm and inviting, using earthy tones."
What Claude Built

From a single six-word design direction, Claude completely rebuilt all three pages with a cohesive new visual identity:

  • New font pairing: Cormorant Garamond (elegant serif headings) + Jost (warm sans-serif body text)
  • Earthy color palette: Linen, oat, sand, terracotta, walnut, bark, amber, sage, and forest green — every color drawn from nature
  • Grain texture overlay: A subtle SVG noise filter on every page gives the feel of natural paper or linen fabric
  • Page-specific theming: Mother's Day uses warm terracotta and amber; Father's Day uses deep forest green and walnut to feel rugged and outdoorsy
  • Card micro-interactions: Gradient accent stripe animates in on hover; images scale up gently; buttons shift color warmly
  • Decorative rings on the home hero and a botanical divider for an organic, handcrafted feel
Terracotta & Walnut Forest & Sage Cormorant Garamond Grain Texture Hover Animations
